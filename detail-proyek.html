Detail Proyek: Portofolio Pribadi

Deskripsi Proyek

Proyek ini adalah website portofolio pribadi yang dibuat untuk memenuhi tugas Ujian Tengah Semester. Website terdiri dari 5 halaman yang saling terhubung, menerapkan Bootstrap 5 untuk tampilan yang menarik dan responsif, serta JavaScript untuk validasi form pada halaman login.

Teknologi yang Digunakan:
  • HTML5 — Struktur halaman
  • CSS3 — Penataan tampilan
  • Bootstrap 5 — Kerangka antarmuka
  • JavaScript — Validasi form & interaksi
Fitur Utama:
  • Navigasi yang mudah digunakan
  • Tampilan responsif untuk semua perangkat
  • Validasi form login di sisi klien
  • Dapat diakses melalui GitHub Pages
